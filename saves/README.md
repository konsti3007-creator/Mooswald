# Beispiel-Spielstand

`village_v1.json` ist ein echtes, weit ausgebautes Dorf (Stand 14. November 2026, Dorfstufe 30, 144 Gebäude, 36 Waldlinge, alle besonderen Bewohner). Wer ihn ansehen möchte:

1. Spiel beenden.
2. Den eigenen Spielstand sichern: `%APPDATA%\Godot\app_userdata\Mooswinkel - Dein kleines Walddorf\village_v1.json` an einen anderen Ort kopieren.
3. Diese `village_v1.json` in genau diesen Ordner kopieren (den eigenen Stand damit ersetzen).
4. Spiel starten – das Dorf wird geladen.

Zurück zum eigenen Dorf: die gesicherte Datei wieder an dieselbe Stelle kopieren. Ein neues Dorf beginnt man jederzeit über Optionen → „Neues Dorf beginnen“.
